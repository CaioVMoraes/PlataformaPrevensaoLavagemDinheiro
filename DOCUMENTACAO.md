# Documentacao do Projeto PLD

O PLD e uma plataforma full-stack para demonstracao de um fluxo de Prevencao a Lavagem de Dinheiro. O sistema apresenta uma fila de alertas, detalhes cadastrais e transacionais, investigacoes, evidencias, relatorios, auditoria e um assistente de apoio ao analista. A interface e desenvolvida em Next.js e consome um microsservico NestJS executado de forma independente; todos os dados sao ficticios e mantidos em memoria, permitindo executar o projeto localmente sem banco de dados ou integracoes externas.

O backend organiza as responsabilidades em modulos de alertas, investigacoes, chatbot, relatorios, auditoria e saude. Controllers expoem os contratos HTTP, services concentram as regras de negocio e repositories encapsulam os dados mockados. O frontend utiliza TanStack Query para estado remoto, Zustand para estado de interface e componentes reutilizaveis para apresentar o fluxo operacional. As decisoes de arquitetura, regras de negocio, convencoes e tecnologias permitidas ficam registradas nos documentos da pasta `.ai/`.

Os principais cenarios demonstrados sao a consulta de alertas com CPF e conta mascarados, a mudanca auditavel de status, o encerramento autorizado de uma investigacao com evidencias e relatorio revisado, o bloqueio de casos incompletos e a consulta ao assistente com justificativa e fontes. O assistente apenas sugere uma classificacao de risco e sempre exige decisao humana; consultas e alteracoes relevantes geram eventos de auditoria.

A qualidade e verificada por quatro testes unitarios e cinco testes de ponta a ponta, totalizando nove testes automatizados. A suite cobre disponibilidade do servico, protecao de dados, regras de encerramento, transparencia do assistente e rastreabilidade. Para executar o projeto, instale as dependencias com `npm install` na raiz e em `frontend/`, inicie a API com `npm run start:dev` e a interface com `npm run dev`; a validacao completa do backend e feita com `npm run lint`, `npm run test:all` e `npm run build`. Repositorio: <https://github.com/CaioVMoraes/PlataformaPrevensaoLavagemDinheiro>.
